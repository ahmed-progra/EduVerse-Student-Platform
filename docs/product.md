# EduVerse — Product Context

register: brand (landing page) / product (app surfaces: dashboard, courses, codelab, lessons)

## What it is

A student-built learning platform for programming. The signature feature is a step-by-step
code visualizer: it executes code line by line and shows variables, loops, and call stacks
changing in real time. Around it: 4 courses (Python, HTML, CSS, C++) with ~30 lessons each,
daily coding challenges, AI hints/review panels, coding battles, a skill tree, and XP rewards.

## Users

University/CS students learning their first languages. They evaluate the site in seconds,
usually at night, on laptops. They are allergic to corporate cosplay and fake numbers.

## Stage & honesty rule

This is a student/university project demo. Copy must be honest: real counts
(4 languages, ~120 lessons), no invented user numbers, no "300M+ students".
"Built by students, for students" is a strength, not a weakness — say it plainly.

## Brand voice

Precise, patient, quietly confident. Show, don't tell: the product demos itself
(live visualizer in the hero) instead of claiming things.

## Direction (decided 2026-06-10 with owner)

Calm premium. Linear/Vercel-grade restraint: one static ambient background element,
one orchestrated entrance on load, scroll reveals that fire once, purposeful hover
micro-interactions. Motion budget is spent on the hero demo, nowhere else.

## Anti-references

- Violet-glassmorphism AI-slop landing pages (gradient text, aurora blobs, floating buttons)
- Continuous ambient animation everywhere (floats, shimmer sweeps, glow pulses)
- Fake stat blocks, "AI-powered" badge-speak, identical icon-card grids

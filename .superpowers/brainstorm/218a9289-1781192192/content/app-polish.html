App Page Polish — Calm Premium

The landing page is calm-premium. The app pages (dashboard, courses, etc.) still use the older style. Here's what I'm proposing to change:

What stays

  • GlassCard component — already solid surface, name is legacy
  • Font family — Bricolage + Work Sans + Geist Mono stays
  • OKLCH palette — all color tokens preserved
  • Easing curve — --ease-out-expo stays

What changes

1

Softer borders

Reduce border opacity from ~0.14 to ~0.08. Cards breathe more, feel lighter.

2

Softer shadows

Wider, more diffuse shadows instead of dense ones. Think: hover shadow = 0 8px 40px / 0.2 instead of 0 4px 16px / 0.35.

3

Restrained accents

Dashboard cards use 4 different accent colors (blue, amber, purple, green). Calm premium uses 1-2 muted hues instead.

4

Consistent spacing

Unify card padding, section gaps, and header sizing across all pages.

5

Empty states

Designed empty/loading/error states for every data-driven page.

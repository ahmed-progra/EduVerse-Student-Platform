Dorm Room — Design Overview

Stripping away everything that makes it look like a generic AI template. The goal: functional, authentic, dark terminal vibe — like a CS student actually built this at 2am.

What goes

  • Aurora + particles — removes .app-ambient::before gradient animation and .app-particles entirely
  • Card hover lift — whileHover: y:-1 becomes y:0. No lift at all
  • Card shadows — .app-card-hover shadow goes to none
  • Card border radius — 16px → 8px (tighter, less decorative)
  • Accent border strips — removes the left-border accent classes (just added these, too decorative)
  • Icon colored backgrounds — icon pills use no background at all
  • Gradient text — none currently, enforce this

What stays

  • Dark palette — oklch(14% 0.022 295) bg, oklch(17.5% 0.026 295) surface
  • Fonts — Bricolage Gr. / Work Sans / Geist Mono
  • Dot grid — the faint radial-gradient(1px) on body
  • Vignette — .app-ambient::after edge darkening (functional, improves readability)
  • Code editor — the visualizer stays as the hero element
  • Easing — --ease-out-expo stays for entrances

What changes

  • Ambient — .app-ambient becomes just the vignette overlay. No ::before, no .app-particles
  • Card radius — border-radius: 16px → 8px
  • Card hover — removed entirely. Cards don't lift, don't glow
  • GlassCard component — whileHover set to undefined
  • Dashboard icons — icon pills lose background/border, just the icon
  • Dashboard stat cards — no accent strips, no tinted numbers, plain text

The result: a dark, focused, tool-like interface. The code and content drive the experience, not the decoration. Think Linear meets a terminal emulator.

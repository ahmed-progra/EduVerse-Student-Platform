Dorm Room v2 — More Distinctive

Beyond just "removing decoration" — giving the UI real character. The code visualizer IS the personality. Everything else gets out of its way.

The moves

1

Monospace data display

Stats, numbers, labels, metadata → all Geist Mono. Reads like a terminal. Headings stay Bricolage, body stays Work Sans. The mix of display + mono is distinctive.

2

Sharp corners (4px)

16px rounded cards scream "SaaS template". Dropping to 4px (from 16px) feels intentional, tool-like, less decorative. Not fully brutalist 0px, but definitely not generic.

3

Naked icons

Remove all icon background pills, circles, and colored containers. Icons float freely beside text — like they do in code editors and developer tools. No decorative framing.

4

Code-comment section headers

Section headings use // Dashboard or /* Recent Activity */ style headers instead of standard h2 tags. Small touch, huge personality shift.

5

Editor-dark surface

Card backgrounds shift from --surface to --editor (even darker). The code editor's color becomes the dominant surface. Everything feels like an IDE.

6

Thinner borders

All card borders drop to 0.5px (hairline). Functional, subtle, less visual noise.

All 6 together make it look like a developer tool — not a generic AI dashboard. Click any you disagree with and I'll adjust.

Why this works

Every "AI-made" dashboard uses the same formula: rounded cards, icon pills, colored accents, gradient blobs, hover lifts, shadows. By systematically removing each of those and replacing them with developer-tool conventions (monospace data, sharp corners, naked icons, comment headers, editor-dark surfaces), the UI becomes unmistakably not a template. It looks like someone who actually codes built it.
